OMOCHI AI のインストール
==========================

1. 「OMOCHI AI」を右の「Applications」フォルダへドラッグします。
2. アプリケーションフォルダの OMOCHI AI を開きます。

OMOCHI AI は Developer ID で署名し、Apple の公証を受けています。
初回に「インターネットからダウンロードされたアプリケーションです」と
表示されたら「開く」を押してください。

必要なもの
- macOS 14 以降（システムの音の文字起こしは macOS 26 以降）
- Claude Code（claude コマンド）をインストールして、ログイン済みであること
  https://code.claude.com/docs/en/setup

使い方・権限・データの保存場所は README を見てください。
https://github.com/Rhizobium-gits/OMOCHI-AI


Installing OMOCHI AI
-----------------------
Drag "OMOCHI AI" to "Applications" and open it. The app is signed with a
Developer ID and notarized by Apple; if macOS says it was downloaded from
the internet, click "Open". Requires macOS 14+ and Claude Code
(the `claude` CLI) installed and signed in.
Switch the display language from the menu bar omochi > Language.
Details: https://github.com/Rhizobium-gits/OMOCHI-AI/blob/main/README.en.md


安装 OMOCHI AI
-----------------
把“OMOCHI AI”拖到“Applications”（应用程序）后打开。本应用已使用 Developer ID
签名并经过 Apple 公证，如果提示“这是从互联网下载的应用程序”，点击“打开”即可。
需要 macOS 14 及以上，并已安装、
登录 Claude Code（claude 命令）。可以在菜单栏的年糕 > 语言 中切换显示语言。
详情：https://github.com/Rhizobium-gits/OMOCHI-AI/blob/main/README.zh-CN.md
